## 1. 目前技術基底

- 前端：原生 HTML / CSS / JavaScript（Starter Kit 示例）
- 建置：Node.js 22+，`scripts/build.mjs`
- 自動檢查：`scripts/check.mjs` + `node:test`
- 部署：GitHub Pages（PR 核准合併 `main` 後 GitHub Actions 自動部署；手動只用於重新部署）
- 後端／資料庫：**未啟用**；有需求才依規格加入
- 相依套件：無

## 2. 元件／模組與資料流

- `site/index.html`：頁面結構
- `site/styles.css`：頁面視覺與響應式樣式
- `site/app.js`：示範互動功能（不保存資料）
- `scripts/build.mjs`：安全檢查檔案後複製至 dist

## 4. 若新增 Supabase / 後端

1. 先確認資料模型、角色權限、RLS、驗證策略及即時同步規格。
2. 測試與正式專案分離；SQL 存 `database/migrations/`，**不要在本範本自動執行**。
3. 先備份、測試遷移，再取得正式環境變更核准。
4. 機密只放安全的金鑰儲存機制，不可放到網站前端或儲存庫。
5. Git／ZIP 回退不代表資料庫可回退；需獨立制定資料庫復原方案。

## 5. 已知限制

此模板是靜態頁面起點；不包含登入、資料庫、即時連線、伺服器端權限驗證或正式資料備份工具。
